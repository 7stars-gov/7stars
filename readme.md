# 7Stars

Репозиторий государства 7Stars. Основной закон — `Constitution 7stars.md`.

```
7stars/
├── Законы/               — законы (ЗК…)
├── Постановления/        — постановления Президента
├── Суд/                  — решения судов и конституционные дела
├── Граждане/             — реестр граждан и их имущества
├── ЧАО/                  — реестр частных организаций
├── ЧЦС/                  — реестр частных центров строительства
├── Частные дороги/       — реестр частных дорог
├── Номерные знаки/       — реестр номерных знаков
├── Внешние постройки/    — реестр внешних построек и схем
├── Historical Places/    — реестр объектов исторической важности
├── Адресный реестр/      — улицы, адреса, переименования
├── ГИБДД/                — ПДД, ШПДП, обращения и нарушения
├── БЗ/                   — реестр Брачных залов
├── GoBank/               — банк и его постановления
└── Городской совет/      — развитие городов и решения совета
```
