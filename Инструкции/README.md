# Инструкции для модераторов служб

Этот файл описывает общий порядок работы с заявкой для всех служб. Специфика каждой службы — в отдельном файле рядом.

## Общий порядок (для любой заявки)

1. **Проверить заявку.** Открой Issue. Все обязательные поля заполнены? Ник указан? Если нет, оставь комментарий с вопросом и жди ответа игрока.

2. **Связаться с игроком только через Issue.** Личные сообщения, Minecraft-чат и любые другие каналы не фиксируются и не проверяются. Всё, что нужно сообщить игроку или получить от него, пишется комментарием в Issue.

3. **Подтвердить личность в игре.** Ник должен совпадать с записью в `Реестры/Граждане/`. Игрок должен быть в сети, когда ты выдаёшь что-то лично.

4. **Выполнить действие в игре.** Выдать номер, зарегистрировать, передать, провести обмен и так далее, по правилам службы.

5. **Закрыть Issue** с одним из статусов и основанием:
   - **выполнено** — действие сделано;
   - **отказано** — с указанием статьи закона, по которой отказано (например, «ЗК15.5: нет подписи Президента»);
   - **перенаправлено** — вопрос относится к другой службе, в комментарии указать какой.

Игровая выдача сама по себе в репозиторий не записывается. В Issue фиксируется только статус, основание и дата.

## Важное

- Отказ должен быть основан на законе. Если закон не предусматривает процедуру, не придумывай её: напиши в комментарии, что процедура не описана, и передай вопрос Президенту (через Issue).
- Все решения попадают в публичный журнал модерации автоматически. Не пытайся обойти это или скрыть решение.
- Если игрок не согласен с отказом, он может обратиться в обычный суд (ЗК1.3).

## Файлы служб

- `регистратор.md` — номерные знаки, имущество, ЧАО и ЧЦС, Historical Places, вопросы по адресам.
- `брачный-зал.md` — регистрация и расторжение брака.
- `гибдд.md` — изъятие транспорта, штрафы, обжалование.
- `gobank.md` — обмен, налоги, взносы, сделки.
- `суд.md` — иски, апелляции, ответы на иски.
- `президент.md` — золотые номера и изменения Historical Places.
