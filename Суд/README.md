# Суд Государства 7Stars

Папка для опубликованных решений судов (Статьи 8, 30, 31 Конституции).

- `Обычный суд/` — решения обычного суда;
- `Верховный суд/` — решения Верховного суда;
- `Конституционные дела/` — поправки к Конституции (Ст. 30) и Конституционный протокол (Ст. 31).

Номерация: `ОС-001-2026`, `ВС-001-2026`, `КД-001-2026`. Каждое решение содержит: номер, дату, состав (в том числе основание роли ИИ по ЗК18.7stars), заявление, доказательства, мотивировку, резолютивную часть, подпись/утверждение Президента (если требуется).
